## Pilot run

This section records the pilot run of the Mise dependency workflow.

The pilot exercised card intake, dependency ordering, pull-request delivery, and
the required CI check against this disposable repository. The `ci` workflow runs
the `tests/` suite for every pull request targeting `main`; a card is ready for
review only after that check passes.
